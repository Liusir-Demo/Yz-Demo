# Yz-Demo

大巴团建互动游戏方案展示页。

## 项目内容

- `index.html`: 页面主体，包含 5 个大巴车上互动游戏方案。
- `style.css`: 页面样式。
- `script.js`: 主持提示展开/收起交互。
- `assets/`: 页面图片和视频素材。
- `tools/`: 素材生成相关脚本。

## 本地预览

直接用浏览器打开 `index.html` 即可查看页面。

- 替换 `assets/images` 中的图片，适配公司真实团建视觉。
